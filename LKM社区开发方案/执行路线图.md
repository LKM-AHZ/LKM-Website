## 0. 使用方式与泳道

- 阶段号沿用父里程碑 `M0.5 / M1.Y / M2.Y / M3.Y / M4 / M5`，另加 **M6 补全轨**（对蓝图的逐章缺口补齐）。
- 状态取值：`待启动 / 施工中 / 待验收 / 已验收`。验收标准写成「当 X → 断言 Y」的可执行形式。
- 泳道：

```
M0（基线，已达成）
 ├─ K-BASE 主线（强串行）：M1 事务发件箱 → M2 模块内聚 → M3 拆 AUTH
 ├─ M-OBS 轨道（与 K-BASE 并行）：M0.5 指标前移
 ├─ L-GATE 后置轨（判据式）：M4 Pulsar biz → M5 容量与治理
 └─ M6 补全轨（与全部轨道并行，非任何轨道前置）
```

- **gate 摘要**：M1 绿 → 进 M2；M2 跨模块 import 归零 → 进 M3；M3 依赖契约成立 → 进入 M4（有消费组）。
  M6 无前置（P2 的 notification 依赖 M6.7 WS 推送）。
- **回归铁律**：任何阶段改动前，全量 `pytest`、`lint-imports`、`ruff` 应绿。

## 2. 里程碑要点卡（精简）

### M1 事务发件箱
- **落点**：`outbox_events`（**复合主键 `(created_at, id)`**；列为 `event_id`(String36) / `routing_key` /
  `payload_json` / `attempt_count` / `next_retry_at` / `locked_at` / `locked_by`），Timescale hypertable +
  压缩；relay Redis 租约选主（`SET NX EX` + 原子续约），leader 内 `FOR UPDATE SKIP LOCKED` 领取。
- **与旧版口径的差异（已更正）**：outbox **没有 `status=failed` 行**——达 `MAX_TRIES=5` 即删行迁
  `event_failures`；列名是 `routing_key`/`payload_json`（非旧文档的 `topic`/`key`/`payload`）。
- **验收口径**：故障注入（裁总线）→恢复后 poller 补齐、事件 1:1（按 `event_id` 去重）；双副本仅一个 leader。

### M2 模块内聚
- **落点**：`app/modules/content/`（含 `articles/`、`blog/` 子包——**仅目录合并，表仍独立**）、
  `app/modules/feed/`；Like 归内容聚合，Follow 归 `interaction`。
- **门禁**：`lint-imports` **5 条 forbidden 契约**（非旧文档写的 4 条）。
- **验收口径**：跨模块 import 归零；REST `/api/v1` 契约不回退；GraphQL 只读 Query 仍可用。

### M3 拆 AUTH
- **落点**：`auth/` 顶层包（`auth/main.py` 独立 ASGI；**旧文档的 `app/main_auth.py` / `app/modules/auth/*`
  路径已不存在**）；`auth/seams.py` 为 app 侧 6 个公开面之一。
- **读模型**：`user:snap` 缓存（版本 CAS 防 LWW + epoch 墓碑 + 负值缓存）+ `by-ids` 批量回退（≤200/批、
  分块、singleflight）；AUTH `user.updated/banned/session_revoke` → 主服务**仅失效 `user:snap`**；
  `user_dim` 只服务报表（`auth/tasks.py` 在失效路径上**同时**刷 user_dim，已回审**保留**）。
- **依赖契约**：启动后台 task 初始化 DB（不阻塞）；readiness 硬依赖 = DB / Redis / Pulsar / AUTH / 验签公钥
  （**Pulsar 与 AUTH 未配置时放行**，仅"已配置却不可达"才 503）；liveness 零外部依赖。

### M4 Pulsar 全量
- **落点**：`persistent://lkm/{auth,biz,system}/...`（9 topic，见《后端规划》§5.2）；points 拆
  reward/stats/tasks 三个 Shared subscription；死信经 `DeadLetterPolicy` 落 `system/dlq`；lag 经 Admin REST
  上报 `pulsar_subscription_backlog`。

### M5 容量与治理（子项）
- **7.2.x**：双级缓存 L1（自实现，非 aiocache）+ singleflight；msgspec 读热序列化（timeline 等，**保持
  snake_case，未按旧蓝图 `to_camel`**）；hypothesis 属性测试。
- **7.2.2** OTel + Collector；**7.2.3** Infisical（**既有 env 优先**，非零明文终点）；**7.2.4** APISIX
  全量替换 nginx（standalone、`acme-webroot` 微型 responder 保留）；**7.2.5** Prefect；**7.2.6** ClickHouse。

### M6 补全轨（P0–P3，12 项，均代码层面完成）
- **P0** M6.1 安全头/CORS/HSTS；M6.2 探针分级（liveness/readiness）+ Pulsar 探活。
- **P1** M6.3 outbox 健壮性（SKIP LOCKED / 陈旧锁 / 失败分类 / 归档）；M6.4 GraphQL 防护——**注意口径已变**：
